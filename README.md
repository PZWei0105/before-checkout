# 下單前 BEFORE CHECKOUT

PZ 專屬的購買判定秘書：顯卡、手機、周邊，現在該不該買。

**App：https://pzwei0105.github.io/before-checkout/**

## 怎麼用

- **放到主畫面**：iPhone 用 Safari 打開網址，點「分享」再點「加入主畫面」。Android 用 Chrome 打開，點右上角「⋮」，選「安裝應用程式」。
- **同步**：在 App 裡下拉畫面，或點右上角的同步狀態。
- **請秘書查**：想查新東西，或下單前想要最新價格，就在「簡報」開一張委託單，或在商品頁按「請秘書重查」。委託單會複製好，貼到 Claude 的新對話送出。秘書查完約 5–10 分鐘，回 App 下拉就看得到。
- **問秘書**：商品頁最下面寫下問題，App 會把問題和判定單一起複製，貼到 Claude 就能問。

## 自動追價

GitHub 每天 09:07、21:07 自動抓一次價格，雙11、黑五這種大促前後改成每小時，完全不用 Claude。

- **來源**：只用條款允許自動抓取的 PChome 24h 和原價屋。Yahoo購物、momo 的條款禁止，所以不用。
- **價格怎麼算**：抓到的價格和秘書查到的比較，採用比較低的那個。跳動超過 25% 的先擋下，App 會標「待秘書確認」。
- **長期數據**：價格紀錄累積滿 30 天後，「近 90 天低點」改用自己的紀錄，走勢也由自動追價計算。
- **沒單賣的商品**：PChome、原價屋沒單賣的商品抓不到，這類仍以秘書查證為準。

## 判定怎麼來

秘書只查事實：官方規格、實測、台灣通路價格、下一代消息、已知問題。判定由 `engine.js` 的 10 條固定規則計算，每一條都附證據。不分潤、不導購。
